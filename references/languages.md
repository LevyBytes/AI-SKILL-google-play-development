# Reference language selection

English is the only bundled reference language. No translated reference files are included. If another reference language is requested, use the English topic and disclose the fallback; the response language can still follow the user.

The screenshot tools accept caller-selected asset locales. Examples using `en-US` and `es-419` describe marketing assets, not translations of this skill. Use [localized content](localized-content.md) to prepare those assets and retain the actual approval and review for each language.
